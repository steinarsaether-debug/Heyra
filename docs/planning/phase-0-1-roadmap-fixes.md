# Phase 0 and 1 Roadmap Fix Worklist

## Goal

Update the roadmap so it reflects what the product has taught us, especially around `vald` governance, instant fishing, compliance priority, and the difference between local-first workflow completion and third-party hardening.

## Worklist

1. Split roadmap delivery language into two tracks where relevant:
   - Local-first product workflow
   - Provider or integration hardening

2. Reframe big-game supply as `Property + Vald/Jaktfelt governance`, not only individual-property listings.

3. Move compliance automation ahead of service marketplace in practical priority, while keeping both inside Phase 1 before Nordic expansion.

4. Keep Service Marketplace in Phase 1 and make it a Norway-readiness requirement before Phase 2.

5. Reframe instant fishing as its own product lane:
   - fast licence discovery
   - quick checkout
   - field proof and area awareness

6. Reduce Phase 1 language scope to Bokmal-first.
   - Nynorsk and English move to later hardening unless they become commercially urgent.

7. Downgrade `shadcn/ui` and Auth.js v5 from roadmap requirements to optional architecture upgrades.

8. Add an explicit Phase 1 compliance track:
   - `ComplianceTask`
   - Hjorteviltregisteret deep-links
   - annual reminders
   - `Sett og skutt`
   - salmon reporting prompts
   - CWD vet/contact directory

9. Add an explicit Phase 1 geospatial discovery track:
   - public map search
   - bbox and nearby search
   - richer fishing discovery
   - stronger listing filters

10. Add a Norway readiness gate before Phase 2:
    - compliance automation live
    - service marketplace live
    - stable local-first booking, trust, and fishing flows
    - provider hardening plan approved

## Suggested order

1. Update roadmap language and phase ordering.
2. Promote `Vald` in the product model and roadmap narrative.
3. Clarify fishing as a separate lane inside Phase 1.
4. Add the Norway readiness gate before Nordic expansion.
